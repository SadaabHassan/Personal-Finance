# 💰 Personal Finance Dashboard – Power BI

This project is a visual and analytical representation of personal financial data to help track income, expenses, savings, and investments over time. Built with Power BI, the dashboard offers an intuitive view of financial health and goal progress.

---

## 📊 Features

- **Total Net Worth** visualization
- **Income vs. Spending** analysis
- **Category-wise Expenses** breakdown (e.g., rent, electricity, transport)
- **Investment Tracking** (e.g., house, stocks)
- **Savings & Goal Monitoring**
- **Interactive Month Selector**
- Modern, user-friendly layout with key metrics displayed clearly

---

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- Data modeling with calculated fields and DAX
- Custom visualizations and slicers
- UI/UX design principles applied for clarity and impact

---

## 📌 Use Cases

- Monitor and optimize personal spending habits
- Set and track financial goals
- Understand asset allocation and net worth
- Gain insights from historical financial data

---

## 📁 File Structure

- `Personal Finance.pbix` – Main Power BI dashboard file
- `Screenshot.png` – Preview of the dashboard layout
- `README.md` – Project overview and documentation

---

## 🚀 Getting Started

1. Open the `.pbix` file using [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Explore the dashboard using filters and visuals.
3. Replace the dummy data with your own (if replicating).
4. Customize visuals or calculations as needed.
